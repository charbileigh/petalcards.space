Install Petalcards

On a PC, open this site in Chrome or Edge and choose the install icon in the address bar, or the browser menu’s install option.

On a recent Mac, Safari also offers File → Add to Dock. On a phone, look for Install app or Add to Home Screen.

You can keep using Petalcards here while the install option becomes available. Open it online once and wait for “Ready for offline use” before going offline.
